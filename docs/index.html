A wallet-owned GEN reserve for an AI agent. The owner locks the maximum amount, GenLayer validators bind an evidence-backed authorization, and only the named executor can settle it once.

1. Lock a budget

The owner binds executor, action scope, payload commitment, policy and expiry. The attached GEN becomes a one-use reserve.

2. Request consensus authorization

Validators independently render policy and evidence. The persisted result includes their source commitments and decision.

3. Settle once

Only the named executor may settle an approved, unexpired budget. The contract transfers the reserved GEN and permanently records the settlement.

4. Read or recover

Read final state from the selected contract. Open or denied budgets may be refunded through the contract's owner/expiry rules.

Verification model

  1. Every budget derives its action hash from a canonical action object on-chain; callers cannot substitute a hash after review.
  2. The app reads `fee-profile.json`, derives a fresh fee estimate from GenLayer for the selected action, and presents the network-provided fee value before submitting.
  3. Each write uses GenLayerJS, `estimateTransactionFeesForWrite`, `writeContract`, `waitForFinalization`, and `isSuccessful`.
  4. The UI re-reads the specific budget from `LATEST_FINAL` state, separating wallet submission, consensus success, and contract state.
