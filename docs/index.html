GENLAYER FEE-AWARE EXECUTION

FeePilot

A wallet-owned GEN reserve for an AI agent. The owner locks the maximum amount, GenLayer validators bind an evidence-backed authorization, and only the named executor can settle it once.

The settlement is an on-chain fee-reserve payment to the named executor. It never claims to verify an unrelated external purchase.

Live contract

Set the deployed Bradbury or Studio contract address below, then connect a wallet to use the real contract state.

1. Lock a budget

The owner defines the only executor, action scope, policy source and expiry. The deposited GEN becomes the maximum one-use reserve.

2. Request consensus authorization

Validators independently render the policy and the evidence URL. Their agreed snapshot hashes are persisted with the approval or denial.

3. Settle once

Only the registered executor can settle an approved, unexpired budget. This transfers the reserved GEN and marks the budget as settled permanently.

4. Read or recover

Read finalized state directly from the selected contract. An open or denied budget can be cancelled by its owner; anyone may recover it after expiry.

Verification model

  1. Every budget derives its action hash from a canonical action object on-chain; callers cannot substitute a hash after review.
  2. Authorization persists policy/evidence snapshot commitments and a consensus decision produced with GenLayer's nondeterministic verification block.
  3. Settlement checks the named executor, linked authorization, approval state, expiry and one-use lifecycle before transferring the locked reserve.
  4. The UI waits for the transaction receipt, re-reads the matching contract record, and reports finalized state rather than treating wallet submission as success.
